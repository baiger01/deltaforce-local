## 运行

在主目录运行 `.venv/Scripts/python.exe -B work/run_local_game.py --source-game ../game --shadow-game ../shadow`，同时启用大厅和地图服务，使用独立影子客户端，1800 秒后自动关闭。其它机器可指定自己的安装目录和独立影子目录，也可使用 `DF_LOCAL_SOURCE_GAME` / `DF_LOCAL_SHADOW_GAME`。地图战局配置目前明确限定零号大坝普通 `2201 / 142201103`；其它地图/难度选项的显示不代表其战局已验收。
